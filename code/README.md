# Code Description

This folder contains the evaluation scripts for the project **Evaluation of LLMs for Mathematical Problem Solving**.

The code is divided into two main parts: the **paper version** and the **updated version**.

## Paper Version

The paper version contains the earlier code related to the experiments reported in the paper. It is kept as a reference to preserve the original evaluation structure used during the paper development stage.

## Updated Version

The updated version is based on the paper version, but has been revised to improve clarity, reproducibility, and robustness. The main updates include clearer code structure, improved evaluation logic, updated answer extraction rules, and clearer result-saving procedures.

The updated scripts for **GSM8K** and **MATH500** have been rerun and checked. The **university-level evaluation** scripts are still being tested and should currently be treated as reference or work-in-progress scripts.

## Note

Some rerun results may differ from the results reported in the paper because model versions and API behaviour may have changed since the original experiments were conducted.
