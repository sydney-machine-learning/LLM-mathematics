# Note on GSM8K Results

Some raw GSM8K output files from the original paper experiments were not fully archived in this repository, including some model-specific outputs for DeepSeek-V3 and GPT-4o.

These missing raw result files are not replaced with newly rerun outputs, because current rerun results may differ from the paper-reported results due to model version and API changes.

Future rerun results, if added, should be stored separately and clearly labelled as current rerun results.
